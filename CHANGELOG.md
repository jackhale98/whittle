# Changelog

## Unreleased

- M3.7 in the app: **part configurations**. A configuration pill in the top bar (desktop and tablet always, so "New configuration…" is one tap away; on the phone a chip, only once the part has a configuration) switches the active configuration and shows each one's status (OK, failed, needs attention, not yet built) from a background rebuild-all check that runs on idle in separate regen slots and is cached by resolved values (never on save). New configurations start from Default or the active one. A **configuration table** (Manage…, a panel over the viewport, lazy-loaded) edits parameters, every feature's expression and option fields, suppression per feature, material, colour, part number and description inline; a pasted TSV block creates configurations in one undo step; the mass column comes from the background builds. **Edit scope is decided at the point of edit**: editing an inherited value edits Default and shows an undoable "Changed in all N configurations"; an overridden value, or one with the one-shot "This configuration only" chip, writes only the active configuration; override markers carry "Reset to default" in the inspector, the Params tab and the table. The feature tree suppresses in this configuration only or in all (the phone: this configuration only). Overrides that no longer apply mark the feature "needs attention" in that configuration with the cause; a missing active configuration is "needs attention", never a silent Default. Export STEP, STL, 3MF or GLB for the active configuration or all, one file each named by part number (else document name and configuration name); name collisions warn and write nothing. Part number and description are editable in the part inspector, which also lists the mass of every configuration. The merge panel names configuration conflicts in plain words. ADR-074, ADR-076.
- Section view fixes: a persistent **Section** chip (Exit section, Flip, Edit) in the viewport on every shell for as long as the cut is on (Esc exits too; closing the panel no longer leaves an invisible cut), and a **rotatable cut plane**: two tilt fields in the panel that take angles with units (`15deg`, `0.2rad`), a numeric offset, and an in-view manipulator with an offset arrow and two rotation arcs (snap to 15 degrees with Shift or a held finger, and onto the X/Y/Z planes within 3 degrees). Face planes tilt too; caps stay filled. The section is still view state, not document data. On the phone the rollback bar now has its own row-height gap, so tapping the row above it selects that row. The plane handles are hidden during push/pull and sketch mode and return afterwards, exiting resets both tilts, and the phone's arcs and offset arrow are covered by touch E2E. ADR-073.
- M3.6 in the app: **feature tree folders** (select features, Add to new folder from the tree menu, the ⌘K palette or the radial menu; inline rename; collapse and expand, remembered per document on this device; drag a folder's run to a new position; suppress, show or hide sketches, or roll back to before a folder; one undo step each), **per-sketch eye toggles** (document data: a consumed sketch can be shown, an unconsumed one hidden, "Reset to automatic"; Show all / Hide all / Reset sketch visibility in the palette), and a **phone Features tab**: a review-only feature tree with a draggable **rollback bar** (a real, undoable rollback edit; no stepper or preview mode). A long press on a row offers Suppress / Unsuppress, Roll to here and the sketch Show / Hide; folders collapse and expand; there is no Delete, Edit, Rename, reordering or folder editing on the phone. The tablet and desktop trees are unchanged. The merge panel shows merge notes (a folder kept in one piece) and names folder and visibility conflicts in plain words. Sketch visibility now treats a sketch whose consuming feature is rolled back as unconsumed. ADR-068.
- Pencil press-and-hold grabs sketch geometry (no tool selected): hold still about 0.3 s on a point, a circle or arc centre or edge, or a line to drag it with the solver (one undo step); a quick stroke still draws, and one that starts at a corner joins it. Pencil hover preselects what a hold would grab.
- Tablet fixes: the sketch toolbar starts with an explicit **Select** tool (arrow) that drops the active drawing tool, and on touch the active tool shows a plain ✕ "Done with <tool>"; the Pencil still draws freehand when no tool is active. A ✕ "Clear selection" sits on the context bubble and the selection inspector, and tapping empty space clears the selection. Sketches consumed by a feature (extrude, cut, revolve, cut-revolve, sweep, loft, hole) hide again on every path once that feature is no longer being edited; a revolve's axis counts as consumed too. The feature tree reveals a nested sketch that the selected feature is built from.
- M3.5 in the app (navigation, input and sketch curves): the left mouse button picks and box-selects (left to right = window, right to left = crossing; Shift adds, Ctrl/Cmd toggles) and never orbits; orbit turns about the surface point under the cursor with a pivot marker; four mouse presets, turntable or trackball, invert zoom and orbit speed in a new **Settings** panel (gear, ⌘K; also on tablet and phone), kept in `wren.navigation`.
- Radial menu on a right click, a finger or Pencil long press, or a held Q: at most seven commands for the selection plus a fixed Repeat slot, flick before it draws, Space repeats; the context bubble stays on tap-select.
- "Which one?" lists overlapping candidates in a stable order (kind, depth, id); Tab and Shift+Tab step the preselection under a still pointer, Enter picks it.
- Shortcuts bind the physical key (`KeyboardEvent.code`) through a keymap you can edit in Settings (conflicts with each other and with browser shortcuts such as Ctrl+W are flagged; `wren.keymap`); holding Ctrl, Cmd or Alt for 0.6 s shows the shortcuts available now. The sketch toolbar follows the same keymap.
- Errors at their cause: needs-attention, error and blocked features name the upstream feature ("Fillet 2 lost its edge because Extrude 1 changed (depth 10 mm → 4 mm)"), the name selects it, blocked chains lead to the root, a deleted cause offers Undo; conflicts name their constraints and geometry, highlight the whole set on hover and mark the last-added constraint's removal as the suggestion.
- Sketch curves in the app: ellipse (Shift+E), elliptic arc (Shift+A), control-point spline (B) and through-point spline (Shift+B), with previews; Enter, a double-click or a double-tap ends a spline, tapping its first point closes it; Pencil ovals and smooth strokes become ellipses and splines.
- Sketch dimensions are drawn with extension lines, a dimension line with arrows, leaders and angle arcs, and their labels drag (one undo step "Move dimension"; the value never changes).
- Feature lineage: a selected face, edge or vertex shows "Made by" its feature and sketch with Edit buttons; a feature selected in the history shows what it is built from and what uses it.
- Convert Entities and linked re-projection ask the kernel for exact curves: ellipses, elliptic arcs and B-splines become exact linked entities instead of polylines.
- The feature inspector, sketch toolbar and overlay, radial menu, settings panel and shortcut overlay load on demand: the initial route is 243.6 kB gzip (it had grown past 250 kB with the M3.5 packages).
- IGES import end to end (M3 gate B1): `.igs` / `.iges` from the Open/Import pickers, drag and drop and the installed app's file handler. Surface models are sewn into solids; an open surface model comes in as a surface body with a warning and is refused as an add/cut/intersect tool.
- Imports are placed and named by the kernel's `import` feature instead of the M1 TypeScript workaround (BREP rewrite, re-import, naming by a no-op intersect). Persistent names of imported faces, edges and vertices and the body ids are unchanged, checked against a golden recorded with the old path, so existing references keep resolving.
- M3 in the app: every M3 tool is wired — extruded and revolved cut, sweep, loft, shell, draft, hole wizard (ISO by default, sizes from the tables, counterbore and countersink overrides), cosmetic thread, mirror, linear and circular patterns (sources from the tree or the model, skip toggles), reference plane, axis and point. Tools ask for each reference in turn with a prompt; reference chips for origin planes and axes and reference features; M3 shortcuts and context actions (inspector and touch bubble).
- Sketch Edit menu in the app: offset, convert entities (projected in the kernel worker, linked), trim / extend, sketch fillet / chamfer and mirror, each one undo step named after the operation; Linked panel with Unlink and Re-pick for lost sources; a Point tool (P); labelled sketch toolbar on touch.
- Linked sketch entities follow their edges on regen through packages/sketch's `reprojectLinked` (kernel-client default).
- Fillet / chamfer with "Propagate along tangent edges" off: the refusal names the tangent edges it would pull in.
- Draft inspector explains the angle (positive: inward away from the neutral plane, on the faces' side).
- M3 acceptance E2E: the ten reference parts built entirely through the UI from their spec steps, mass checked within 0.1 % at the baseline and every CSWP stage.
- Sketch editing (M3 workstream 1, `@wren-cad/sketch/edit`): offset entities (one driving signed `offset` dimension, joins, caps, solved downstream of planegcs), convert entities (linked, fixed, re-projected in place, lost sources reported), trim/extend, fillet/chamfer with virtual sharps, mirror tied by symmetric constraints; linked geometry named in conflict explanations.
- Test fixtures: the M3 reference-part suite (PLAN 12A), 10 original parts with specs, drawings, derived masses, CSWP stages, a spec-to-`WrenDoc` builder, real-kernel goldens (parts using M3 features are skipped until they merge) and independent FreeCAD checks (all 40 cases within 3e-12 of the analytic volume).
